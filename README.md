## Sobre

Protótipo de site para divulgar e distribuir a **textura JuhCanary**, a mais usada pelos
jogadores do servidor **Rede Canary** de Minecraft. A textura não é oficial do servidor, mas tem
o apoio dele.

## Visão Geral

- apresentação da textura e do que ela muda no jogo
- **downloads** separados por versão do Minecraft
- seção de **feedback**
- links para as redes sociais

## Rodando Localmente

Projeto estático, sem dependências: basta abrir o `index.html` no navegador.
